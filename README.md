# Bank Management System

A terminal-based Bank Management System built with Python as a practical project to apply Object-Oriented Programming (OOP) concepts for the first time in a real application.

---

## 📌 About The Project

This project simulates the core operations of a simple banking system. Users can create accounts, log in, manage their balance, deposit and withdraw money, transfer funds, and view account information.

The main goal of this project was to practice:
- Object-Oriented Programming (OOP)
- Structuring a multi-feature application
- Handling user input and validation
- Working with files for data storage
- Creating a cleaner terminal interface using the `Rich` library

---

## ✨ Features

- Create a new bank account
- Secure login system
- Show current balance
- Deposit money
- Withdraw money
- Transfer money to another account
- View transaction history
- View account information
- Logout functionality
- Clean and organized terminal interface (using Rich)

---

## 🛠️ Technologies Used

- **Python 3**
- **Rich** library (for tables, panels, and progress bars)
- Text file for data storage

---

## 🧠 Concepts Practiced

- Object-Oriented Programming (Classes & Objects)
- Functions and program structure
- Conditional statements and loops
- File handling (reading & writing)
- Input validation
- Error handling (basic)
- Terminal UI design with Rich
